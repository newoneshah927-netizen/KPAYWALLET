# 📚 HBS (Hazara Board System)

A complete educational management system for board examination results, paper checking, and student management built with HTML, CSS, and JavaScript using IndexedDB.

## 🌟 Features

### 👨‍🏫 Teacher Module
- **Subject-Specific Paper Checking**: Teachers only see and check papers for their assigned subject
- **Mark Entry**: Check papers with marks (0-50)
- **History**: View all previously checked papers
- **Recheck Management**: Approve or reject recheck requests for their subject

### 👨‍🎓 Student Module
- **Result Viewing**: View personal results with detailed marks
- **Grade System**: Automatic grade calculation (A+, A, B, C, D, F)
- **Profile Management**: View and update profile information
- **Recheck Application**: Apply for recheck with KPAY payment (Rs. 2,500)
- **Result History**: View all previous results

### 👨‍💼 Editor Module
- **Student Status**: View all students and their paper status
- **Create Result Sheets**: Generate result sheets for all students
- **Upload Results**: Upload individual or bulk results
- **Publish Results**: Publish results online for public viewing
- **Edit Marks**: Modify student marks before publishing
- **Payment Verification**: Verify KPAY payment screenshots

### 👨‍💻 Admin Module
- **Student Management**: View all students with their marks
- **Bulk Upload**: Upload students via CSV file
- **Teacher Management**: Approve or reject teacher registrations
- **Paper Overview**: View all papers with status
- **Session Management**: Create new sessions or reset current session
- **Editor Management**: Add or remove editors
- **Activity Logs**: View all system activities
- **Recheck Overview**: View all recheck requests

## 🛠️ Technology Stack

| Component | Technology |
|-----------|------------|
| Frontend | HTML5, CSS3, JavaScript (Vanilla) |
| Database | IndexedDB (Browser-based) |
| UI Design | Glass-morphism with blur effects |
| Icons | Font Awesome 6 |
| Styling | CSS Flexbox & Grid |
